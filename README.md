# Tubes 2 DOM Traversal

React + TypeScript di frontend dan Rust di backend.

## Struktur Proyek

```text
.
|-- frontend/
|   |-- public/
|   `-- src/
|-- backend/
|   |-- src/
|   `-- tests/
|-- contracts/
|-- docs/
|-- infra/
|-- samples/
|-- scripts/
`-- .gitignore
```

## Pembagian fungsi

- `frontend`: aplikasi React + TypeScript.
- `backend`: service Rust dan test backend.
- `docs`: dokumentasi proyek dan laporan.
- `infra`: kebutuhan deployment, container, atau environment.
- `samples`: file contoh untuk eksperimen atau pengujian lokal.
- `scripts`: script bantu proyek.
